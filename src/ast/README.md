# Абстрактное Синтаксическое Дерево (AST)

Абстрактное Синтаксическое Дерево (AST) — это иерархическая древовидная структура данных, которая представляет синтаксическую структуру исходного кода. Это результат работы парсера. В отличие от *конкретного* синтаксического дерева (parse tree), AST является *абстрактным*, потому что оно опускает многие синтаксические детали, которые не важны для дальнейших этапов компиляции, такие как скобки, точки с запятой, и т.д., концентрируясь на сути конструкций языка.

## Зачем нужно AST?

AST — это ключевая структура данных во всем процессе компиляции:
1.  **Промежуточное представление:** Оно служит удобным промежуточным представлением программы, с которым легко работать программно. Вместо того чтобы оперировать плоским списком токенов или, тем более, сырым текстом, последующие этапы (семантический анализ, оптимизация, генерация кода) работают с этим деревом.
2.  **Анализ кода:** Древовидная структура идеально подходит для анализа. Мы можем легко обходить дерево (например, с помощью паттерна "Посетитель" (Visitor)), чтобы проверить типы, найти объявления переменных, проанализировать области видимости и выполнить другие семантические проверки.
3.  **Трансформация кода:** AST легко модифицировать. Это используется в ходе оптимизаций, когда компилятор преобразует дерево для повышения производительности итогового кода.
4.  **Генерация кода:** Генератор кода обходит AST и рекурсивно генерирует исполняемый код на целевом языке для каждого узла дерева.

## Структура AST в нашем компиляторе

В нашем проекте определения всех узлов AST находятся в `src/ast/node.ts`. Все узлы наследуются от базового класса `ASTNode`.

Каждый узел в дереве представляет определенную конструкцию языка. Например:
-   `Program`: Корневой узел всего дерева.
-   `FunctionDeclaration`: Представляет объявление функции. Его дочерними узлами могут быть `Identifier` (имя функции), `ParamList` (параметры), `Type` (возвращаемый тип) и `BlockStmt` (тело функции).
-   `VariableDeclaration`: Объявление переменной.
-   `BinaryExpr`: Бинарная операция (например, `a + b`). Дочерние узлы — это левый и правый операнды (`left`, `right`) и оператор (`operator`).
-   `IfStmt`: Условный оператор `if`.

Процесс построения этого дерева из вывода SLR-парсера происходит в `src/ast/builder.ts`. `ASTBuilder` принимает последовательность действий свертки от парсера и конструирует соответствующие узлы AST, связывая их в единую древовидную структуру.
