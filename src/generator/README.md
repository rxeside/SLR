# Генератор Кода (Code Generator)

Генерация кода — это заключительный этап работы компилятора. Его задача — преобразовать промежуточное представление программы, которым у нас является Абстрактное Синтаксическое Дерево (AST), в исполняемый код на целевом языке.

В нашем случае, компилятор является **транспилятором** (или source-to-source компилятором), поскольку он переводит код с нашего собственного языка на другой высокоуровневый язык — JavaScript.

## Процесс Генерации Кода

Генератор кода, реализованный в `src/generator/generator.ts`, работает путем обхода AST, которое уже было успешно проверено семантическим анализатором. Для каждого узла дерева генератор создает соответствующий фрагмент JavaScript-кода.

Как и семантический анализатор, генератор кода использует паттерн **"Посетитель" (Visitor)** для обхода дерева:
1.  `CodeGenerator` реализует интерфейс `ASTVisitor`.
2.  Для каждого типа узла AST (`IfStmt`, `BinaryExpr`, `FunctionDeclaration` и т.д.) существует метод `visit...`, который отвечает за генерацию кода для этого конкретного узла.
3.  Процесс начинается с вызова `visit` для корневого узла `Program`.
4.  Каждый метод `visit...` рекурсивно вызывает `visit` для своих дочерних узлов и затем конструирует из результатов итоговую строку кода.

### Пример:

При посещении узла `BinaryExpr` (бинарное выражение):
1.  Генератор рекурсивно вызывает `visit` для левого операнда, чтобы получить строку JS-кода для него.
2.  Затем он вызывает `visit` для правого операнда.
3.  Наконец, он соединяет полученные строки с помощью оператора из узла `BinaryExpr`.

Таким образом, для узла, представляющего `a + 5`, генератор скомбинирует результат посещения узла `a`, строку `+` и результат посещения узла `5`, чтобы получить итоговую строку `"a + 5"`.

## Результат работы

Результатом работы генератора является одна большая строка, содержащая полный JavaScript-код, семантически эквивалентный исходной программе. Эту строку затем можно сохранить в `.js` файл и исполнить с помощью любой среды выполнения JavaScript, такой как Node.js или браузер.
