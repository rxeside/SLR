# Простой Компилятор (Транспилятор)

Этот проект представляет собой учебный компилятор для простого, статически типизированного языка. Компилятор написан на TypeScript и транслирует исходный код в JavaScript.

## Архитектура Компилятора

Компилятор имеет классическую модульную структуру, где каждый этап является отдельным, независимым компонентом, обрабатывающим результат работы предыдущего этапа.

### Этапы Компиляции:

1.  **[Лексический Анализ](./src/lexer/README.md)**
    -   **Вход:** Строка исходного кода.
    -   **Выход:** Последовательность (массив) токенов.
    -   **Описание:** Лексер разбивает исходный код на минимальные смысловые единицы (токены), такие как ключевые слова, идентификаторы, операторы и литералы.

2.  **[Синтаксический Анализ (Парсинг)](./src/slr/README.md)**
    -   **Вход:** Последовательность токенов.
    -   **Выход:** Абстрактное Синтаксическое Дерево (AST).
    -   **Описание:** Парсер, используя [грамматику языка](./src/grammar/README.md), проверяет, что последовательность токенов образует синтаксически корректную программу. В процессе он строит [AST](./src/ast/README.md) — древовидное представление структуры кода. В проекте используется SLR-парсер.

3.  **[Семантический Анализ](./src/analyzer/README.md)**
    -   **Вход:** Абстрактное Синтаксическое Дерево (AST).
    -   **Выход:** Проверенное и аннотированное AST.
    -   **Описание:** Этот этап проверяет программу на семантические ошибки, которые не могут быть пойманы на уровне синтаксиса. Он включает в себя проверку типов, проверку объявлений переменных и функций, а также управление областями видимости с помощью [Таблицы Символов](./src/symbolTable/README.md).

4.  **[Генерация Кода](./src/generator/README.md)**
    -   **Вход:** Проверенное AST.
    -   **Выход:** Строка с кодом на JavaScript.
    -   **Описание:** Заключительный этап, на котором генератор кода обходит AST и транслирует его в семантически эквивалентный код на JavaScript.

## Как запустить

1.  **Установка зависимостей:**
    ```bash
    npm install
    ```
2.  **Сборка проекта:**
    ```bash
    npm run build
    ```
3.  **Запуск компиляции:**
    ```bash
    npm start
    ```
    Компилятор прочитает исходный код из файла `program.txt`, обработает его и выведет сгенерированный JavaScript-код в консоль.
